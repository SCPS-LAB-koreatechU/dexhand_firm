일반 조작과 재연결
1. CAN 채널에서 can1 선택 → CAN 연결 확인.
2. 보드가 마지막 PWM을 유지하고 있으면 '현재 자세 이어받기'.
   보드 전원을 새로 켜 이어받을 PWM이 없으면 이를 안내하고 출력을 시작하지 않습니다.
   이 경우 빈손에서 의도적으로 '손 펼치기'를 선택한 뒤 조절합니다.
3. 슬라이더를 움직이면 값이 전송됩니다. 목표/전송/마지막 확인 PWM은 서로 다를 수 있습니다.
4. 통신 오류가 나면 원인을 해결한 뒤 CAN 재연결 → 현재 자세 이어받기.
   연결 확인·재연결만으로 출력이 시작되지 않습니다.
   이전 연결의 대기 명령과 보내지 못한 목표는 폐기합니다.
5. 멈춤/HOLD 또는 Esc는 마지막 PWM을 유지합니다. PWM 전원 차단 기능은 아닙니다.

엄지 캘리브레이션
1. '엄지 캘리브레이션' 버튼으로 창을 엽니다. 열 때 기존 스트리밍을 HOLD합니다.
2. 왼쪽 당김(채널13/GPIO13), 오른쪽 당김(채널15/GPIO18),
   TIP/엄지 끝(채널14/GPIO14) 중 하나를 선택합니다.
3. CAN 확인 후 '현재 PWM 이어받기'를 눌러 조절을 시작합니다.
4. ±5/±10µs 또는 정수 PWM 입력 → '선택 모터로 전송'.
   선택 모터의 목표만 바뀌고 나머지 14개 목표는 보존합니다.
   속도 제한과 좌우 당김 합 제한은 계속 적용됩니다.
   마지막 확인 PWM은 ESP32가 적용했다고 응답한 명령입니다. 실제 각도/장력 측정값이 아닙니다.
5. 원하는 지점에서 '입력값을 풀림으로 기록' / '입력값을 당김으로 기록'.
   직접 입력해 기록한 값은 실제 응답이 확인됐다는 뜻이 아니므로 마지막 확인 PWM도 확인하세요.
6. JSON 초안 저장. 기본 위치는 ~/bhl_calibration_drafts 입니다.
7. SDK 설정 초안 내보내기는 새 폴더에 right_hand.json, dexhand.yaml, APPLY.txt를 생성합니다.
8. 캘리브레이션 창을 닫으면 HOLD합니다. 현재 프로그램을 종료하기 전까지 초안은 메모리에 남습니다.

현재 펌웨어 허용 범위
왼쪽 당김: 700~2300µs
오른쪽 당김: 700~1900µs
TIP: 700~2100µs
이 범위 밖으로는 전송하지 않습니다. 초안은 500~2500µs 안에서 기록할 수 있습니다.

캘리브레이션 적용 방식
초안을 저장하거나 내보내도 실행 중인 프로필/허용 범위는 바뀌지 않습니다.
