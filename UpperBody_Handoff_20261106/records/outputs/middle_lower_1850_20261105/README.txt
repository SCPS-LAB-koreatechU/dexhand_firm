중지 아래 1850us 운용 설정 (2026-11-05)

변경 대상: 오른손 CAN 채널 6 / GPIO22의 접힘 목표만 1750 -> 1850us. 펼침 850us 및 다른 모든 모터의 펴기/접기 값은 유지한다.
이 설정은 기본 프로파일을 덮어쓰지 않는 별도 운용 프로파일이다. 장치의 프로필 태그 bdad07a4는 기존 펴기/접기 초기값과 2300us 수신 상한을 가진 펌웨어의 식별값이다. 운용 목표 1850us는 그 수신 범위 안에서 선택한 PC 측 목표이며, 펌웨어 프로파일 JSON 자체를 바꾸지는 않는다.

기존 펌웨어 79610de6은 GPIO22에서 1750us 초과 값을 거부한다. 1850us를 실제로 시험하려면 앞서 제공한 DexHandRight_RXOnly_PWMCap2300_20261105.zip을 업로드하고 맞는 SDK cap2300 패치를 적용해야 한다. 펌웨어 ZIP은 새로 바뀌지 않았다.

적용 준비
1. config/dexhand_camera_middle1850.yaml을 SDK bhl_hand_sdk/config/에 둔다. 이 파일만 복사한다고 현재 구동값은 바뀌지 않는다.
2. RAM 시험 파일은 ram_scripts/ 내용을 /run/user/1000/bhl_hand_camera_session/에 둔다.
3. 새 펌웨어와 SDK cap2300 적용 후, 관찰 GUI 실행 때 BHL_HAND_CAMERA_CONFIG를 이 별도 YAML 경로로 지정한다. 로봇 관찰 모드에서는 사람 손 대응표를 읽거나 덮어쓰지 않는다.
4. 중지 시험을 명시적으로 선택할 때 run_middle_flex_test.py --middle-lower 1850을 사용한다. 기본 실행은 기존 1750us이며, 1850 모드는 활성 기본 SDK가 cap2300 프로필인지 먼저 검사한다.

현재 보드에는 1850us 명령을 보내지 않았다. 중지 세 모터는 기존 접힘값 825/1750/2000us HOLD 상태이며 자동 펼침은 없다. 펴질 때 다른 손가락과 걸린 문제가 있어 이 설정만으로 기계적 간섭이 해결되었다고 판단하지 않는다.
