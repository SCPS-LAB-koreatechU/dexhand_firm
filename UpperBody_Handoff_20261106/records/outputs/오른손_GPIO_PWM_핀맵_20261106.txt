오른손 GPIO / 핀 / PWM 설정표 — 2026-11-06
기준: 기존 펌웨어/실행 설정 79610de6. 단위: us(마이크로초).
채널은 손 보드의 CAN 배열 순서이며 개별 CAN ID가 아니다. 손 전체 CAN 노드는 61(0x3D)이다.
핀 번호는 ESP32 GPIO 번호다. 보드 커넥터의 물리적 몇 번째 핀을 뜻하지 않는다.
당김 최소=풀림/펴기 0%, 당김 최대=접기 100%. PWM 숫자가 클수록 더 당기는 것은 아니다.

 7 | 검지 위 | GPIO32 | 1750 -> 700 | 700~1750 | PWM 감소

통신/주의사항
- CAN TX GPIO1 / RX GPIO3, 1Mbps. GPIO1/3은 통신용이며 서보 핀과 다르다.
- 서보 PWM은 50Hz. 검지 위/아래는 GPIO32/25이며 예전 GPIO34/35가 아니다.
- 엄지 CAN 채널 13/14/15는 왼쪽 당김/TIP/오른쪽 당김이다. 오른손 좌우 당김 합 제한은 채널 13+15다.
- 중지 아래(GPIO22)의 현재 접힘값은 1750us. 요청한 1850us는 대기 운용 설정이며 실제 전송하지 않았다.
- 모든 오른손 모터의 수신 상한 2300us는 새 펌웨어 bdad07a4용 대기 변경이다. 기존 표의 펴기/접기값을 일괄 2300으로 바꾸는 뜻이 아니다.
- 이전 테스트 라벨과 CAN 배열 순서는 다르다: 검지 1/2 -> CAN 7/8, 중지 3/4 -> CAN 5/6, 약지 5/6 -> CAN 3/4, 소지 7/8 -> CAN 1/2.
- 관절 각도/실제 장력 실측표가 아니라 사용자가 확정한 PWM 목표 프로필이다.
