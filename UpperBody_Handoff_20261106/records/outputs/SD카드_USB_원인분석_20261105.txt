진단 대상: sunrise@172.18.49.21 / RDK X5 / 2026-11-05

확인된 직접 원인
GUI 로그/캘리 저장 실패는 SD카드 통신 오류 뒤 ext4 루트 파일시스템이 읽기 전용으로 전환된 결과다.
현재 /dev/root / ext4 ro,relatime. SD카드 장치 /dev/mmcblk1p2.
블록 장치 자체의 ro 플래그는 0이다. 카드 잠금 스위치 때문에 전체가 읽기 전용이 된 것으로 볼 근거는 없다.

기록된 발생 순서 (부팅 후 초)
4318.337: 기존 USB 연결 분리
4323.119: 새 포트 경로에서 USB 3.0 허브 인식
4326.789: ZED-2i HID 인식. 영상 USB 인터페이스와 /dev/video*는 없음.
4329.011: SD 컨트롤러 All sample phases bad!
4329.017 / 4339.700 / 4350.382: mmc1 tuning execution failed: -5
4351.219: SD카드 쓰기 I/O 오류 시작
4351.584: ext4 journal abort
4353.969: 루트 파일시스템 read-only 재마운트
4395.750 이후: SD카드 읽기 I/O 오류도 확인됨

MMC 누적 오류
명령 타임아웃 14 / 데이터 타임아웃 229 / 데이터 CRC 34 / 튜닝 실패 3 / ADMA 오류 0
현재 ios: 50MHz, 4bit, SD high-speed, 신호 전압 설정 3.3V.
이 값은 컨트롤러 설정이며 물리 전압 측정값이 아니다.
카드는 부팅 때 SDR104로 인식되었고 현재 high-speed 상태이지만 통신 실패의 근본 원인은 확정되지 않았다.

확인한 다른 조건
루트 남은 용량 약 36.16GiB. 저장공간 부족으로 발생한 오류가 아니다.
SoC 온도 약 65~66도. sysfs에 등록된 95도 이상의 trip 온도에는 도달하지 않았다.
부팅 시 FAT 파티션의 이전 비정상 종료 경고도 있었지만, 현재 튜닝/CRC/타임아웃 오류의 단독 원인으로 단정할 수 없다.
SD CID 제조일 필드: 2020-09. 제조일만으로 수명 소진이나 고장을 판단할 수 없다.
USB 3.0 허브는 5000Mbps로 인식된다. HID의 12Mbps 표시는 해당 HID 인터페이스 속도일 뿐, 그 자체로 카메라 영상 링크 속도를 뜻하지 않는다.
보드 내부 허브도 USB 트리에 나타나므로 외부 허브를 사용 중이라고 단정하지 않는다.

원인 후보와 한계
1. SD카드/슬롯 접촉 또는 카드 자체 불안정: 튜닝 실패, CRC, 데이터 타임아웃과 일치한다.
2. 보드 입력 전원/케이블 불안정: USB 재연결 직후 SD 오류가 시작되어 공통 원인 후보지만 실측 근거는 아직 없다. 사용자가 현재 어댑터 정격 5V/5A를 확인했다. 정격은 X5 공식 요구사항에 맞으므로 정격 부족을 원인으로 볼 근거는 없다. 케이블/커넥터 전압 강하나 순간 변동은 정격 확인만으로 배제하지 못한다.
3. SD 호환성/컨트롤러·커널 문제: 현재 로그만으로 배제할 수 없다.
카메라 영상 미인식은 첫 부팅 때부터 있었고 SD 오류는 나중에 시작했다. SD 오류 하나가 초기 영상 미인식까지 설명한다고 할 수 없다.
보드 5V 입력 전압 실측 센서는 이번 조회에서 확보하지 못했다. sysfs의 코어 전압/레귤레이터 설정을 5V 실측으로 해석하지 않는다.

다음 원인 분리
사용자 확인: 보드 어댑터 OUTPUT 5V/5A, ZED 카메라는 별도 전원 없이 보드 USB에서 전원을 받는다. X5 공식 전원 정격은 충족한다. SD카드/슬롯/통신 문제를 우선 점검하고, 필요하면 보드 입력부 전압을 실측해 전원 변동을 구분한다.
전원을 끈 뒤 카드/슬롯 상태를 확인하고, 별도 PC의 리더에서 데이터/이미지를 우선 보존한 후 마운트 해제 상태에서 파일시스템을 검사한다.
정상 전원과 다른 정상 SD카드에서 같은 문제가 재현되는지 비교하면 카드와 보드/전원 원인을 구분할 수 있다.
SD카드의 전원 인가 중 분리, 강제 쓰기 재마운트, 마운트된 루트의 수정 fsck, 포맷/재설치/펌웨어 변경은 하지 않았다.
USB 절전 해제 시도는 진단 기록 파일 생성이 읽기 전용 오류로 실패한 시점에 중단됐으며 sysfs 변경은 실행되지 않았다.
